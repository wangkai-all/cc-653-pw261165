# 调查交叉表估计器

已知**各地区人数（行边际）**、**各出行方式人数（列边际）**和一张**参考分布**，
估计完整的非负交叉表；部分地区不存在某种交通方式的格子是**结构零**，必须恒为 0。
网页可编辑两组边际总数、参考权重、业务禁用格与单元格上下限，并实时展示每次调整
对最终分配的影响。

## 运行

纯静态页面，无需构建：

```bash
# 任选一种静态服务器（直接 file:// 打开也可以，脚本均为普通 <script>）
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 方法

### 1. 可行性先于求解（最大流 + 最小割见证）

交叉表可行性等价于带容量的二分图流问题：

- `源点 → 地区 i`：行边际总量（扣除已固定的下限流量）
- `地区 i → 方式 j`：仅当该格**未被业务禁用**时存在，容量 = 上限 − 下限
- `方式 j → 汇点`：列边际总量（扣除下限流量）

用 Dinic 求最大流；最大流等于总需求才可行。不可行时**不依赖迭代报错**，
而是从残余网络的最小割 reachable 集合给出 Hall 型见证，明确指出：

- 哪一组地区（可达行集合）
- 组内总需求是多少
- 它们能连接哪些方式、这些方式的总容量是多少
- 缺口多少、哪些禁用关系切断了连接（结构性不可行）
- 或哪些格子上限被饱和（上下限挤占型不可行）

### 2. 可行后求最贴近参考权重的非负表（有界 IPF / KL 投影）

```
minimize  Σ x_ij · log(x_ij / p_ij)
s.t.      行/列边际精确匹配，l_ij ≤ x_ij ≤ u_ij，禁用格不进入变量集
```

交替执行行、列半投影；每个半投影是“缩放 + 截断到 [l, u]”的一维单调问题，
缩放因子由二分法求根（无上下限时退化为经典 IPF 的乘性迭代）。输出包含：

- 完整分配表（热力着色）与相对上一版可行解的逐格差值
- 每行、每列的目标值/实际值/绝对误差/相对误差
- 迭代轮数、最大误差、KL 散度与**停止原因**（收敛 / 达迭代上限 / 停滞 / 退化）
- 对数刻度的误差下降曲线（带悬浮提示）

### 3. 参考零与业务禁用严格分开

| 类型 | 含义 | 处理 |
|---|---|---|
| 业务禁用（结构零） | 该组合现实中不存在 | 不进入变量集合与流网络，**任何平滑都不会向其填值**，恒为 0 |
| 参考权重为 0 的允许格 | 先验上不倾向，但组合允许存在 | 二选一：**ε 平滑**（替换为显式小正数后参与迭代）或**硬零**（精确保持 0） |

硬零模式下若边际总量无法仅靠正权重格满足，迭代会停滞并给出停止原因，
而不是偷偷把零权重格填上数值。

## 内置示例

1. **基础示例（3×3）**：整数参考权重，可纸笔核对；远郊无地铁（禁用）。
2. **总量一致但局部不可行**：行列合计都是 200，但甲地区只能进入容量 90 的方式 A，
   而它有 100 人——诊断应直接报出缺口 10 的地区组，而非“迭代失败”。
3. **单元格上限挤占**：在①上把「城区×地铁」限为 55 人（无约束解约 73.65），
   观察流量如何被挤到其他格子；上限若低于可行性下限 50 则整体不可行。
4. **下限冲突**：要求远郊×公交至少 45 人，但远郊总共只有 40 人，静态检查拦截。
5. **参考零 ≠ 业务禁用**：3×2 表，对比 ε 平滑与硬零两种策略的分配与停止原因。
